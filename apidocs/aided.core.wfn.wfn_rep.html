Bases: object

Structure of Arrays of AIM file / representation using numpy arrays.

nmos: Number of Molecular Orbitals nprims: Number of Gaussian Primitives nats: Number of Nuclei (Atoms) atnames: Atom names atpos: Atomic positions atcharge: Atomic charges centers: Atomic center upon which each primitive is based types: Gaussian primitive type for each atom expons: Exponents for each basis function occs: Occupancy number for each MO energies: Energy of each MO coeffs: Coefficients for each MO total_energy: Total energy of the system virial_energy: Virial energy of the system
