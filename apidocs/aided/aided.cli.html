aided.cli

aided.cli

Commandline utilities and main method call.

Automically discovers top level application modules located in the “apps” directory to be called and turns them into a sub-command:

aided <command> [<options>]

Each command module must expose “register(subparsers)”, which adds its own arg-parser and sets “func” to dispatch to it.
