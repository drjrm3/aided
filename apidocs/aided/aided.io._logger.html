aided.io._logger._get_logger(log_level: str = 'DEBUG', log_file: str = 'aided.log', initialize: bool = False) → logging.Logger[source]

Get a logger instance that can be used throughout the application.

Args: log_level (str): The logging level to use. Defaults to “DEBUG”. log_file (str): The file to write the log to. Defaults to “aided.log”. initialize (bool): If True, will reinitialize the logger even if it already exists.

Returns: _logger (logging.Logger): The logger instance.
