Electron Density Representation.

High level class which represents the information needed to express the ED but is abstracted away from the type of file.

Types of representations may include:

  • .wfn files (AIMFile)

  • starting_radius – Radius to generate the surface in Bohr.

  • max_distance – The max distance (in Bohr) from the atom to find a point on the surface.

  • tol – The tolerance to use when searching for the surface.

trace_gradient_to_atom(x: float, y: float, z: float, method: str = 'L-BFGS-B', step_limit: float = 0.25, max_iter: int = 100, tol: float = 0.0) → Tuple[str, ndarray][source]

Trace the gradient of the ED to an atom.

Perform this by using scipy.optimize.minimize to find the location where the gradient is zero but the electron density (rho) is maximized.

Parameters:

  • x – Cartesian points in global space.

  • y – Cartesian points in global space.

  • z – Cartesian points in global space.

  • method – Optimization method to use (BFGS, CG, Netwon-CG, etc.)

  • step_limit – Maximum distance to move in one step.

  • max_iter – Maximum number of iterations to perform.

  • tol – Distance from the atom at which to stop searching. If tol is zero, stop when objective is minimized as normal.

Returns:

Name of the atom found. atom_position: Position of the atom found.

Return type:

atom_name
